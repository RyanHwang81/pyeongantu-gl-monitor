# GL v4 후보 사전 등록 (2026-10-23)

이 문서는 보류 구간 결과를 계산하기 **전에** 커밋했습니다. 아래 정의와 통과 기준은 결과를 본 뒤에 바꾸지 않습니다. 결과는 `docs/model-v4-holdout.md`에 따로 적습니다.

## 숨기지 말아야 할 점

이 사전 등록은 완전히 눈을 가린 시험이 아닙니다. PR #10·#11·#12에서 1972–2026 전체 표본을 이미 봤고, 아래 후보도 그 결과를 보고 골랐습니다. 2006–2026 구간의 결과도 그 전체 표본 안에 들어 있었습니다. 그래서 이 시험은 "처음 보는 자료에서의 검증"이 아니라 다음 두 가지를 확인하는 것입니다.

- 1972–2005 자료만으로 정한 규칙이 2006–2026에서도 같은 방향으로 유지되는가
- 미리 정한 기준을 한 번에 통과하는가

통과하더라도 실제 운영에 들어간 뒤의 성적이 진짜 검증입니다.

## 구간

| 구간 | 신호월 | 쓰임 |
|---|---|---|
| 훈련 | 1972-01~2005-12 (시장 국면은 1980-08부터 비교) | 자산 안내 방향을 정함. 수익률 창이 2005-12를 넘는 신호는 뺌 |
| 보류 | 2006-01~ (수익률 자료 끝까지) | 한 번만 평가 |

## 후보

| 후보 | 계절 (경기 판정) | 날씨 (시장 국면) | 자산 안내 | 주식 비중 |
|---|---|---|---|---|
| C0 현행 | 공개 v3 확인 국면 | 없음 | 화면 목록(`REGIME_ASSETS`)이 뜻하는 방향 | 70/65/60/50% |
| C1 v4-A | 공개 v3 확인 국면 (입력 그대로) | M1 (PR #12) | 훈련 구간에서 정한 방향 | 계절 + 날씨 규칙 (선택) |
| C2 v4-B | PR #10 변형 a4 (실질 GDP .15 + 실질 서비스 소비 .15 추가) | M1 | 훈련 구간에서 정한 방향 | 계절 + 날씨 규칙 (선택) |

- **C0 화면 목록의 방향**: 실적 = 경기민감 우위, 금융 = 성장주 우위, 역금융 = 가치주 우위, 역실적 = 방어 업종 우위로 읽습니다. 화면에 없는 축은 중립(0)으로 둡니다.
- **M1**: 성장은 경기민감 − 방어 업종 6개월 누적(.5)과 10Y−3M 6개월 변화(.5), 유동성은 2년물 3개월 변화 역(.5)과 Baa−10Y 6개월 변화 역(.5)입니다. 점수는 v3와 같은 방식이고, 2개월 확인 없이 히스테리시스 사분면을 씁니다.
- **계절 + 날씨 규칙**: 계절 비중(70/65/60/50, 지연 1개월, 확인이 없으면 유지)에서 날씨 비중(같은 표, 지연 0) 쪽으로 차이의 50%만 이동합니다. 나머지는 10년 국채 근사에 둡니다.

## 자산 안내를 정하는 규칙 (훈련 구간에서만)

대상 스프레드는 성장 − 가치(−HML)와 경기민감 − 방어(내구재·제조·유통 대 비내구재·헬스케어·유틸리티) 두 개입니다.

계절(확인 국면, 지연 1)과 날씨(M1, 지연 0) 각각에 대해, 국면별로 훈련 구간의 12개월 뒤 평균을 구합니다.

- 평균이 +1%p 이상이면 앞쪽(성장, 경기민감)을 고릅니다.
- 평균이 −1%p 이하이면 뒤쪽(가치, 방어)을 고릅니다.
- 그 사이면 중립입니다.

## 시험과 통과 기준 (보류 구간)

| 번호 | 무엇을 | 통과 기준 |
|---|---|---|
| H1 날씨 선행 | 확정 계절 전환 때 M1이 먼저 같은 방에 간 비율과 중위 선행. G_m과 v3 G의 교차상관 | 시장 먼저 비율 ≥ 대조군 + 10%p, 중위 선행 > 대조군 중위, G 교차상관 최대 시차 > 0이고 그 상관 ≥ 0.2 |
| H2 계절 안내 | 훈련에서 정한 방향을 보류 구간에서 따랐을 때의 12개월 롱숏 수익(방향 × 스프레드) | 두 스프레드를 합친 평균 > 0, HAC t ≥ 1.65. 그리고 보류 구간 12개월 이상인 국면 가운데 3/4 이상에서 부호가 유지됨 (스프레드별) |
| H3 날씨 안내 | H2와 같은 시험을 M1 날씨와 그 안내로 | H2와 같음 |
| H4 비중 규칙 | 계절 + 날씨 규칙과, 같은 평균 비중을 고정한 포트폴리오의 월 수익 차 | 연 차이 > 0이고 HAC t ≥ 1.0 |
| H5 현행 목록 | C0 방향을 따랐을 때의 12개월 롱숏 수익 | 기록만 함. 평균 > 0, t ≥ 1.65면 현행 목록이 보류 구간에서 맞은 것 |
| H6 실시간 안정성 | 2006-06~2026-06 반기 말 ALFRED 빈티지로 다시 계산한 마지막 달 G 부호와 국면이, 같은 달 수정 이력과 같은 비율 | G 부호 일치 ≥ 80%. 국면 일치는 기록만 함 |

HAC는 Newey-West, 시차 12입니다. H6는 성장 입력 4개(PERMIT, INDPRO, PAYEMS, UNRATE)만 ALFRED 빈티지로 바꿉니다. ICSA와 유동성 입력은 지금 자료를 씁니다. ICSA는 수정이 작고, 금리·스프레드는 수정되지 않습니다.

## 결정 규칙

- H1 통과: 날씨를 참고 표시로 앱에 넣을 수 있습니다.
- H2 또는 H3 통과: 통과한 쪽의 자산 안내를 쓸 수 있습니다. 둘 다 실패하면 자산 안내는 내립니다.
- H4 통과: 비중 안내를 붙일 수 있습니다. 실패하면 비중 숫자는 화면에 두지 않습니다.
- C2는 C1이 실패한 시험을 C2가 통과할 때만 C1 대신 고릅니다. 아니면 입력을 바꾸지 않는 C1을 고릅니다.
- 이 규칙은 권고이고, 운영 모델을 바꿀지는 Ryan이 정합니다.

# GL v4 후보 보류 구간 검증 (2026-10-23)

사전 등록: `docs/model-v4-preregistration.md`(결과 계산 전에 커밋). 재현: `scripts/v4_holdout.py`.

## 결론: v4 후보가 보류 구간에서 통과했는가

1. **날씨(시장 국면 M1)의 선행만 통과했습니다(H1).** 2006–2026 확정 계절 전환 14번 가운데 시장이 먼저 같은 방에 간 것이 64%, 중위 5개월 앞섰습니다. 대조군은 53%, 1.3개월입니다. G_m과 v3 G의 상관은 19개월 앞에서 가장 큽니다(0.27). 날씨를 참고 표시로 넣을 근거는 있습니다.
2. **자산 안내는 계절·날씨 모두 실패했습니다(H2·H3).** 1972–2005로 정한 스타일·업종 방향을 2006–2026에 따랐을 때 12개월 롱숏 수익은 계절 +2.5%(t 0.97), 날씨 +2.0%(t 1.11)입니다. 기준은 t 1.65였습니다. 결정 규칙대로라면 화면의 자산 안내는 내려야 합니다.
3. **지금 화면 목록(C0)은 보류 구간에서 반대로 움직였습니다(H5).** 목록이 뜻하는 방향을 따르면 12개월 롱숏 수익이 훈련 구간 −3.3%(t −2.2), 보류 구간 −7.6%(t −3.8)입니다. 화면 목록이 틀렸다는 PR #11의 결론이 보류 구간에서도 확인됐습니다.
4. **비중 규칙은 실패했습니다(H4).** 계절 + 날씨 규칙은 같은 평균 비중을 고정한 포트폴리오보다 연 +0.23%p, t 0.80입니다. 기준은 t 1.0이었습니다. 비중 숫자는 화면에 두지 않는 것이 결정 규칙입니다.
5. **C2(서비스 입력 추가)는 C1이 실패한 시험을 하나도 통과하지 못했고, H1에서는 기준에 1.4%p 모자랐습니다.** 결정 규칙대로 C1(v3 입력 그대로)을 고릅니다. H6(실시간 빈티지) 결과는 아래 6절에 있습니다.

권고(채택은 Ryan이 정함): **계절 = v3 확정 국면, 날씨 = M1 참고 표시, 자산 안내와 비중 숫자는 내림.**

## 1. 훈련 구간에서 정한 안내와 보류 구간 결과

## 남은 한계

- 완전히 눈을 가린 시험이 아닙니다. 사전 등록 문서에 적었듯이 PR #10~#12에서 전체 표본을 이미 봤습니다. 날씨 명세 M1과 후보 구성도 그 결과를 보고 정했습니다. 그런데도 통과한 것은 H1 하나뿐이라, 과적합 쪽으로 기운 결과는 아닙니다.
- 보류 구간의 계절 전환은 17번(매칭 14번), 국면별 보류 개월은 22~56개월입니다. 12개월 창이 겹치므로 실제 독립 표본은 그보다 훨씬 적습니다.
- H6는 성장 입력 4개만 빈티지로 바꿨습니다. ICSA와 유동성 입력은 지금 자료를 썼고, C2의 GDP·서비스 소비 빈티지는 보지 않았습니다.
- 수익률·스타일 자료는 Ken French(~2026-08), 국채는 금리로 만든 근사입니다.
- 날씨에 발표 지연이 없다는 가정은 그대로입니다. 실제 업종 수익률 자료는 한두 달 늦게 나옵니다.

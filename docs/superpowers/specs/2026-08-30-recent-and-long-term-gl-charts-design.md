# 최근 이동·장기 국면 GL 차트 분리 설계

## 목표

정량 보조모델의 단일 4분면 차트가 월간 근거리 변화와 연간 장기 위치를 동시에 설명하면서 생기는 축·거리 해석 혼선을 없앤다. 독자는 첫 화면에서 `최근 무엇이 움직였는가`를 읽고, 별도 장기 지도에서 `역사적으로 어디에 있는가`를 비교한다.

## 승인된 방향

기존 `월간 / 연간` 모드 전환형 단일 차트를 두 개의 목적별 카드로 분리한다.

1. **최근 12개월 이동**
   - 월간 데이터만 사용한다.
   - 12개월과 24개월 기간을 선택할 수 있다.
   - 최근 데이터에 맞춘 확대축을 사용하고 Growth와 Liquidity의 눈금 범위를 각각 독립적으로 계산한다.
   - 성장축은 작은 월별 편차도 읽을 수 있도록 최소 `-0.2 ~ +0.2`를 포함하고, 유동성축은 실제 범위에 맞춰 별도로 확장한다.
   - `축별 확대 · X/Y 축 범위가 서로 다르며 장기 국면 지도와 이동 거리를 직접 비교하지 않습니다`라는 설명을 항상 노출한다.
   - 시작점·분기 말·현재점만 라벨링하고, 과거 점은 옅게 현재점은 진하게 표시한다.
   - 시작 대비 현재 `ΔG`, `ΔL`과 각각의 해석(거의 보합/개선/악화)을 상단 요약으로 표시한다.
   - 원점 주변 `|G| < 0.15`, `|L| < 0.15` 중립·전환 구간을 시각적으로 표시한다.

2. **장기 GL 국면 지도**
   - 달력연도별 월간 G/L의 연평균값을 사용한다.
   - 전체 또는 연대별 기간을 선택할 수 있다.
   - 축은 항상 `-3 ~ +3`으로 고정한다.
   - 연도 라벨과 실선 궤적으로 역사적 위치·국면 전환을 비교한다.
   - `연간 평균 · 고정축 ±3`을 명시한다.

3. **선택 상세 패널·레짐 히스토리**
   - 기존 우측 월별 구성요소·자산 성과 패널을 유지한다.
   - 최근 이동 점 클릭은 해당 월을 선택한다.
   - 장기 지도 점 클릭은 해당 연도의 마지막 월을 선택한다.
   - 기존 전체 월별 레짐 히스토리 리본과 iframe 높이 통지를 유지한다.

## UI 구조

정량 보조모델 KPI 아래를 다음 순서로 배치한다.

1. 좌측 상단: 최근 12개월 이동 카드
2. 좌측 다음: 장기 GL 국면 지도 카드
3. 좌측 하단: 전체 레짐 히스토리 카드
4. 우측: 선택 월 상세 카드

기존 따뜻한 종이색·깊은 잉크·절제된 브랜드 색을 유지한다. 새 요소는 Signal & Flow `DESIGN.md`의 monitor-card, meta-label, hairline-rule 계층을 따른다.

## 데이터와 계산 경계

- `build.py`의 FRED 수집, 216개월 z-score, 가중치, EMA, 레짐 판정은 변경하지 않는다.
- 연간 값은 현재와 동일하게 달력연도 월간 G/L 산술평균을 사용한다. 완료되지 않은 당해연도는 최신 발표월까지의 연중 평균임을 화면과 툴팁에 명시한다.
- 최근 이동의 `ΔG`와 `ΔL`은 선택 기간의 첫 월 대비 마지막 월 차이다.
- 데이터가 2개월 미만이면 변화 요약을 `자료 부족`으로 표시하고 차트는 안전하게 비운다.

## 접근성·반응형

- 차트 제목·설명·기간 선택은 스크린리더가 읽을 수 있는 실제 텍스트와 label을 사용한다.
- 키보드로 기간 select와 SVG 점을 선택할 수 있게 각 점에 `tabindex=0`, `role=button`, `aria-label`을 제공한다.
- 390px와 360px에서 컨트롤·요약 카드가 한 열로 쌓이고 페이지 수준 가로 넘침이 없어야 한다.
- 모바일에서는 차트 라벨 수를 더 줄이고 툴팁이 화면 밖으로 나가지 않아야 한다.

## 비목표

- GL 산식·지표·가중치·데이터 공급원을 바꾸지 않는다.
- WordPress 포스트 ID·slug·iframe URL·KR/EN 라우팅을 바꾸지 않는다.
- `gl-internal.html`을 공개 글에 노출하지 않는다.
- 별도 차트 라이브러리나 외부 런타임 의존성을 추가하지 않는다.

## 검증 계약

1. 템플릿 계약 테스트가 두 차트의 제목·ID·설명·고정축 표기를 확인한다.
2. 생성 HTML에 플레이스홀더가 남지 않고 public/internal 분리가 유지된다.
3. 최근 차트의 기간 선택은 월간 프리셋만, 장기 차트의 기간 선택은 연간 프리셋만 제공한다.
4. 장기 차트 축은 항상 `[-3, 3]`이며 최근 차트는 X/Y 각 데이터 범위에 맞춘 독립 확대축을 사용한다.
5. 직접 공개 URL과 WordPress iframe이 HTTP 200이며 새 두 제목이 렌더 DOM에 존재한다.
6. 360/390/1440px에서 페이지 수준 가로 넘침이 없고 두 차트와 선택 패널이 읽을 수 있다.
7. GitHub Actions build/deploy가 성공하고 canonical URL에서 새 버전을 read-back한다.

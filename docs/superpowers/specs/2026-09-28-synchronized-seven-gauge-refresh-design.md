# 정량 모델·일곱 계기판 동시 갱신 설계

## 승인된 발행 규칙
정량 GL 빌드(기존 매월 1·16일 및 수동 실행)마다 일곱 계기판의 **현재 관측월 스냅샷도 생성**한다. 실제 확인된 지표만 출처·관측일·비교 기준과 함께 표시하고, 확인되지 않은 지표는 `미확인`과 마지막으로 확인한 날짜를 표시한다. 미확인 때문에 정량 모델 발행을 중단하지 않는다. 저자 확인 기록인 `book_dashboard.json`의 과거 행은 수정하지 않는다. 정량 모델과 제27장 지표는 별도의 판독 체계다.

## 자료·판독 경계
- 기존 FRED API 키와 수집기만 재사용해 달러인덱스 대용지표 `DTWEXBGS`, 하이일드 스프레드 `BAMLH0A0HYM2`, 원달러 환율 `DEXKOUS`의 최근 원자료를 수집한다. 해당 관측월 원자료와 직전 관측월 원자료가 모두 있어야 월평균의 방향을 계산한다. 진행 중인 달은 `잠정 관측`이며 확정 월간 판정이 아니다. 상승한 달러·스프레드·원달러는 L에 역방향 영향을 준다. 정확히 동일하면 보합이다. 마지막 관측일·두 월평균·공식 FRED URL을 공개한다.
- 글로벌 PMI(S&P Global), 반도체 수출(MOTIE), 주도 산업 이익 전망, 연준 다음 행보 기대(CME FedWatch)는 공개 시계열의 정의·라이선스·판독 규칙을 확인하지 않고 다른 대리지표로 대체하지 않는다. 같은 달의 근거가 `book_dashboard.json`에 저자 확인 기록으로 추가돼 있으면 사용하고, 없으면 `미확인`으로 표시한다. 오래된 6월 화살표를 복제하지 않는다.
- 원천 자료 호출에 실패한 지표도 미확인으로 처리하고 실패를 빌드 로그/스냅샷 메타데이터에 남긴다. FRED 핵심 GL 모델 수집이 실패하면 기존처럼 빌드 자체가 실패해 배포하지 않는다.
- 원고 판정은 일곱 지표 전부가 확인된 월에만 `confirmed`; 진행월·누락이 있는 월에는 `provisional` 및 전월 판정 유지. 화면은 숫자/상태만 보여주고 매매 행동을 제시하지 않는다.

## 구성·검증
`build.py`에 순수 스냅샷 함수와 세 FRED 원자료 수집을 더하고, 빌드 안에서 GL 산출 후 계기판 스냅샷을 만들어 같은 HTML 산출물에 묶는다. `gl_template.html`은 헤더를 `현재 점검월 · 관측 N/7 · 마지막 저자 확정월`로 바꾸고, 행마다 확인일·출처/미확인 사유를 노출한다. `README.md`와 Actions 계약은 자동 동시 갱신·결측 정책을 명시한다. tests는 부분 관측, 신호 방향, 전월 기록 비변조, 오류, 재실행, DOM을 검증한다. 로컬 빌드 후 공개 Pages와 WordPress 한·영 임베드 모바일·데스크톱을 확인한다.

## 비범위
월간 확인 기록의 자동 확정, 새 외부 크론/서비스, 유료 컨센서스, 비검증 뉴스로 지표 채우기, 7개 중 일부 미확인 시 전체 발행 중단은 하지 않는다.

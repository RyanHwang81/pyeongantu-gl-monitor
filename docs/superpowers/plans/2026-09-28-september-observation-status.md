# 2026-09 월중 GL 관측 상태 공개 계획

결정: 9월의 성장·유동성 점수를 결측 이월로 추정하지 않는다. 마지막 계산 좌표의 월은 8월로 두되, 새로 발표된 8월 자료는 기존 산식으로 재계산하고 이전 좌표와 달라졌음을 고지한다. 9월의 실제 관측 가능 현황을 4분면 바로 위에 한·영 병기한다. 주 판독(제27장 7개 지표)은 원고의 확인 기록만으로 갱신하고, FRED 보조모델과 혼동하지 않는다.

1. 기존 dist 및 공개 HTML을 별도 백업한다. FRED API의 실제 9월 관측과 실패한 graph CSV endpoint를 확인한다.
2. 테스트 선행: API 수집 파싱, 9월 현황의 날짜·건수·결측 기준, HTML 경고, 9월 좌표가 새로 생성되지 않음을 검증한다.
3. FRED API 키를 Actions secret에서 읽어 graph CSV timeout을 해결한다. 원본 계열과 기존 산식·가중치·최소 유효 가중치는 바꾸지 않는다. 키·URL의 query token이 로그나 산출물에 노출되지 않게 한다.
4. 실제 15개 원본을 재수집하여 산출물을 빌드한다. 이전 8월 좌표와 과거 값의 변경 여부를 비교하고, 9월 점은 생성되지 않는지 확인한다. 기존 역사 데이터가 재작성된다면 원인을 판별하고 불필요한 소급 변경은 배포하지 않는다.
5. 대상 파일만 커밋·push한다. Pages Actions 완료 및 공개 readback 후 WordPress KR/EN 임베드에서 한·영 문구와 360·390·1440px 가로 넘침/가독성을 검증한다.

Rollback: 백업한 dist와 소스 파일을 기준으로 별도 되돌림 커밋 후 Pages 재배포. WordPress 페이지는 임베드라 변경할 필요가 없으면 건드리지 않는다.

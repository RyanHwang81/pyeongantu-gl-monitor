# 국면별 자산 목록과 시간 어긋남 — 사전 등록 (2026-10-23)

이 문서는 아래 시험의 결과를 계산하기 **전에** 커밋했습니다. 결과는 `docs/asset-timing-check.md`에 적습니다. PR #11·#14에서 이미 본 결과(확정 국면 뒤 수익률이 다음 국면의 모습을 보임, 화면 목록이 보류 구간에서 반대로 움직임)가 이 질문의 출발점이므로, 완전히 눈을 가린 시험은 아닙니다.

## 시험할 목록 (화면의 `REGIME_ASSETS`를 측정 가능한 자산으로 옮김)

| 국면 | 우위 (목록 → 측정 자산) | 열위 (목록 → 측정 자산) |
|---|---|---|
| 실적 | 산업재·소재 → 제조(Manuf), 경기소비재 → 내구재(Durbl)·유통(Shops), 금융 → 기타(Other) | 유틸리티 → Utils, 장기채 → 10년 국채, 필수소비재 → 비내구재(NoDur) |
| 금융 | 성장주 → B/M 하위 30%(Lo 30), IT/플랫폼 → HiTec, 바이오 → 헬스케어(Hlth), 장기채 → 10년 국채 | 에너지 → Enrgy, 은행 → 기타(Other), 소재 → 제조(Manuf) |
| 역금융 | 에너지 → Enrgy, 배당/가치주 → B/M 상위 30%(Hi 30), 단기채 → 5년 국채 | 고밸류 성장주 → Lo 30, 장기채 → 10년 국채 (리츠는 측정 안 함) |
| 역실적 | 필수소비재 → NoDur, 헬스케어 → Hlth, 유틸리티 → Utils, 통신 → Telcm, 현금 → TB3MS, 금 → 금 월간 가격 | 경기소비재 → Durbl·Shops, 산업재 → Manuf (하이일드는 측정 안 함) |

- 업종과 B/M 포트폴리오는 Ken French Data Library의 시가총액가중 월간 수익률입니다. 국채는 FRED 금리로 만든 par-bond 근사, 현금은 TB3MS, 금은 datahub gold-prices 미러의 월간 가격입니다.
- Ken French 10개 업종의 "기타(Other)"에는 금융 외 업종도 섞여 있어 대용입니다.

**목록 점수 S**: 창 안의 우위 자산 평균 수익에서 열위 자산 평균 수익을 뺀 값입니다. 각 자산은 창 안에서 복리로 계산합니다. S > 0이면 목록이 맞은 것입니다.

## 시간 기준

- 신호월 t는 v3가 판정한 달입니다. 판정은 한 달 뒤에 공개되므로, 실제로 쓸 수 있는 첫 창은 t+2월부터 t+1+h월까지입니다. 이 창을 **k = 0**으로 둡니다.
- k만큼 옮긴 창은 t+2+k월부터 t+1+k+h월까지입니다. k < 0이면 공개 전, 즉 사후에만 알 수 있는 시점입니다.
- k는 −18~+18, h는 6개월이 기본이고 12개월은 참고입니다.
- 훈련 구간 신호는 창이 2005-12 안에서 끝나는 달만, 보류 구간 신호는 2006-01 이후 달입니다. 보류 구간은 한 번만 평가합니다.
- 통계는 Newey-West HAC t(시차 h)입니다.

## 가설과 판정 기준

| 가설 | 계산 | "그렇다"로 판정하는 기준 |
|---|---|---|
| H-a 시간 이동 | v3 확인 계절(마지막 확인 국면 이어 붙임)에 자기 목록을 붙이고, k = −18…+18에서 평균 S(k)를 계산. 순환 이동은 k = 0에서 다음 국면 목록, 이전 국면 목록을 붙인 S | 훈련에서 S가 가장 큰 k*가 −3 이하이고 S(k*) > 0, t ≥ 2. 보류에서 같은 k*의 S > 0, t ≥ 1.65 |
| H-a′ 순환 한 칸 | k = 0에서 다음 국면 목록 | 훈련 S > 0, t ≥ 2. 보류 S > 0, t ≥ 1.65 |
| H-b 국면 안에서는 맞는가 | 공개 v3 `regime`(미확인 포함, 경계 제외)이 붙은 달 m의 같은 달 수익(h = 1, 지연 없음). 사후 기준선 | 월 단위 S > 0, t ≥ 2(훈련)·t ≥ 1.65(보류). 구간 단위(구간마다 평균 S 하나) 적중률 ≥ 60% |
| H-c 날씨에 붙이기 | 시장 국면 M1(지연 0), k = 0 창 | 훈련 S > 0, t ≥ 2. 보류 S > 0, t ≥ 1.65 |
| H-d 수준 기준 국면 | 성장 = CFNAI-MA3 부호, 유동성 = −NFCI 월평균 부호로 나눈 사분면(지연 1), k = 0 창 | H-c와 같음 |
| H-e 목록 항목 | 항목별로 그 자산 수익에서 측정 자산 전체 평균을 뺀 값을, 그 항목이 속한 국면의 달에서 평균. 정렬 4가지(계절 k = 0, 국면 안 동시, 날씨, 수준)와 훈련 구간의 k = −18…+18 | 훈련에서 정렬 4가지 모두 목록과 반대 부호이고, 보류에서도 기본 정렬(계절 k = 0)에서 반대 부호면 "목록 자체의 문제"로 표시 |

## 원인 판정 규칙

- **타이밍이 원인**: H-b가 그렇다이고, 계절 k = 0은 틀리며, H-a 또는 H-a′가 그렇다일 때.
- **정의가 원인**: H-d만 그렇다일 때.
- **목록이 원인**: H-b도 아니다일 때. 국면 진행 중에도 목록이 맞지 않는다는 뜻입니다.
- 여러 경우가 겹치면 모두 적습니다.

## 맞출 방안 후보 (보류 구간 S로 비교)

1. 확정 뒤에는 다음 국면 목록을 보여 줌 (H-a′와 같은 계산)
2. 시장 국면에 목록을 붙임 (H-c와 같은 계산)
3. "이 국면에서 이미 오른 자산"(국면 안 동시, 설명용)과 "다음 국면에 유리했던 자산"(1번)을 나눠 보여 줌. 앞쪽은 사후 정보라 성과 비교에서 빼고, 뒤쪽은 1번 결과를 그대로 씀

권고는 보류 구간에서 S > 0, t ≥ 1.65를 만족하는 방안 가운데 t가 가장 큰 것으로 합니다. 만족하는 방안이 없으면 "어느 정렬로도 목록을 투자 안내로 쓸 근거가 없다"를 권고로 둡니다.

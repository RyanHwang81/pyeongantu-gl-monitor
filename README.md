# 평안투 GL 레짐 모니터

미국 FRED 성장·유동성 정량 모델을 첫 화면에 두고, 마지막 계산월의 점과 당월의 잠정 추정점을 구분해 보여주는 대시보드입니다. 원고 제27장의 성장 3개·유동성 4개 수동 확인 기록은 아래쪽의 날짜가 붙은 별도 계기판으로 남기며, 정량 점수와 섞지 않습니다.

## 산출물

| 파일 | 용도 | 방법론 섹션 |
|---|---|---|
| `dist/index.html` | **공개용** — 외부 배포 | 미포함 |
| `dist/gl-internal.html` | **내부용** — 산식 검토 | 포함 |
| `dist/en.html` | **영문 공개용** — 같은 모델·같은 수치 | 미포함 |
| `dist/gl_data.json` | 계산 결과 원본 (재사용·검증용) | — |
| `book_dashboard.json` | 제27장 일곱 지표의 월간 확인 기록 | — |

두 파일 모두 외부 의존성 없는 단일 HTML입니다. 폰트만 Google Fonts에서 로드하며, 그 외 데이터·차트·로직이 파일 안에 모두 들어 있어 더블클릭만으로 열립니다.

## 자동 갱신 구조

FRED는 브라우저 직접 호출(CORS)을 허용하지 않으므로, **서버 측에서 재빌드 후 배포**하는 방식으로 자동화합니다.

```
GitHub Actions (매월 1일·16일; 수동 실행 시도 동일)
   └─ build.py 실행
        ├─ book_dashboard.json 기존 저자 확인 기록 보존
        ├─ 일곱 지표 현재월 스냅샷 생성(검증 자료만 반영, 나머지 미확인)
        ├─ FRED 21개 시계열 + 주가/금 시세 다운로드
        ├─ 미국 매크로 G/L 점수 재계산 (신규 월 자동 추가)
        └─ index.html / gl-internal.html 재생성
   └─ GitHub Pages 자동 배포
```

**동시 갱신 규칙:** 정량 모델을 빌드할 때마다 일곱 계기판도 같은 실행에서 현재월 점검 스냅샷을 생성합니다. `DTWEXBGS`(달러), `BAMLH0A0HYM2`(하이일드), `DEXKOUS`(원달러) 세 칸은 FRED 원자료의 당월·전월 월평균을 비교하여 관측일/출처를 표시합니다. 진행월 방향은 잠정입니다. 나머지 PMI·반도체 수출·이익 전망·연준 기대는 원문·측정 정의가 확인된 저자 월간 기록이 입력되지 않으면 **미확인**으로 둡니다. 이전 달의 화살표를 현월로 복제하거나 다른 대리지표로 바꾸지 않습니다. 7개가 미확인 상태여도 정량 모델은 발행하되 관측 N/7, 현재 점검월, 마지막 저자 확정월을 함께 표시합니다. 확정 원고 기록의 과거 행은 수정하지 않습니다. FRED 월간 좌표는 해당 월의 유효 가중치가 G/L 각각 0.4 이상일 때에만 `months`에 추가합니다. 8월처럼 직후에 발표된 8월 관측분은 현재 공개된 자료로 재계산하므로 **8월 31일 당시의 정보집합을 재현한 점은 아닙니다.**

진행 중인 달에 실제 관측이 하나라도 있으면, **월간 히스토리와 별도의** `meta.provisional_point`를 산출합니다. 해당 달에 관측된 지표는 월중 자료로 변환하고, 아직 미발표인 지표는 마지막 발표된 **변환 신호**(YoY·금리 변화 등)를 이월합니다. 원시 수준을 단순 이월해 가짜 변화율을 만들지 않습니다. 지표가 아예 없거나 변환 신호가 3개월보다 오래됐다면 잠정점을 만들지 않습니다. 기존 z-score·가중합·EMA 계산은 그대로 사용하지만 입력은 확정 월간 자료가 아니므로 점은 속 빈 마름모로 그리고, 월중 날짜·실측 및 이월 비중·지표별 출처 월을 공개합니다. 잠정점은 레짐 히스토리, 연간 평균, 지속 기간, 자산 성과에 넣지 않습니다. 월간 계산 점과 잠정점은 동일한 확정도로 해석할 수 없습니다.

> **월 2회 실행 이유** — PERMIT·INDPRO·PAYEMS 등 주요 지표는 해당 월 종료 후 2~3주 뒤 발표됩니다. 1일에만 실행하면 직전 월이 아직 미발표 상태일 수 있어, 16일에 한 번 더 실행해 누락을 방지합니다. 신규 데이터가 없으면 커밋 없이 종료합니다.

## 설치 및 실행

### 로컬 실행

```bash
pip install pandas numpy certifi
python3 build.py --out dist
```

옵션:

- `--out DIR` 출력 디렉터리 (기본 `dist`)
- `--template PATH` 템플릿 경로 (기본 `gl_template.html`)
- 환경변수 `FRED_API_KEY` 지정 시 FRED 공식 observations API 사용 (Actions에서는 저장소 secret 필수, 키는 로그나 산출물에 넣지 않음)
- 환경변수 `GL_CACHE=/path` 지정 시 원본 CSV를 해당 폴더에 캐시 (재실행 시 네트워크 부하 감소)

### GitHub Actions / GitHub Pages 설정

1. 이 폴더의 파일을 저장소 루트에 커밋 (`build.py`, `gl_template.html`, `README.md`)
2. `update.yml` 을 `.github/workflows/update.yml` 경로로 저장
3. 저장소 **Settings → Pages → Source** 를 `GitHub Actions` 로 설정
4. build job은 `self-hosted, macOS, gl-monitor` runner에서 실행합니다. FRED graph CSV는 해당 runner에서도 timeout 되었으므로, 저장소 Actions secret `FRED_API_KEY`를 등록해 FRED 공식 API로 수집합니다. 산식은 변경하지 않습니다.
5. **Actions** 탭에서 `Run workflow` 로 첫 실행 → 이후 매월 1일·16일 09:00 UTC 자동 반복

공개 URL은 `https://ryanhwang81.github.io/pyeongantu-gl-monitor/` 이며 `index.html`(공개용)만 iframe/블로그에 노출합니다.  
`gl-internal.html`은 방법론 검토용이며 공개 글/iframe/버튼에서 링크하지 않습니다.

## 수동 확인 기록 — 제27장 일곱 지표

**성장 (G)** — 글로벌 제조업 PMI, 한국 반도체 수출, 주도 산업 이익 전망치

**유동성 (L)** — 연준의 다음 행보 기대, 달러인덱스 추세, 하이일드 스프레드, 원달러 환율 위치

각 지표는 원자료의 움직임(`direction`)과 G/L에 미치는 방향(`effect`)을 구분해 기록합니다. 성장 3개와 유동성 4개의 다수결로 좌표를 정하며, 성장 쪽 동률은 이익 전망치, 유동성 쪽 동률은 신용스프레드를 우선합니다. 지표가 미발표이거나 그래도 판정이 안 서면 새 방을 선언하지 않고 이전 방을 유지합니다. 자동 관측만으로 저자 월간 기록을 확정하지 않으며, 확인 가능한 출처 자료가 없으면 `pending`으로 표시합니다.

## 미국 매크로 정량 보조모델 v2.0

성장(G)의 PERMIT .28, INDPRO .24, PAYEMS .24, UNRATE .14, ICSA .10 구성은 유지합니다. 유동성(L)은 M2SL .18, DGS2 .18, NETLIQ .15, DOLLAR(DTWEXBGS) .15, T10Y3M .12, BAA10YM .12, TOTALSL .10입니다. DGS2는 월평균 3개월 변화의 역, DOLLAR는 월평균 YoY의 역입니다. NETLIQ는 월평균 WALCL−WTREGEN−RRPONTSYD×1000의 YoY이며 백만 달러로 단위를 통일합니다. RRPONTSYD 관측 시작 이전만 RRP=0으로 가정합니다. 그 이전에 모든 역레포 제도가 없었다는 뜻은 아니며, 시작 이후 결측은 0으로 채우지 않습니다.

변경 이유는 네 가지입니다.

- **이월 착시:** 미발표 지표를 빼고 평균을 내면 구성 변화만으로 축이 움직일 수 있습니다. 변환 신호의 끝단만 3개월 이월합니다. 원시 수준이나 중간 결측은 채우지 않습니다. 지표와 합성치의 평균·표준편차에는 이월값을 제외하고 직전 실측월 통계로 이월월을 계산합니다.
- **원점 인접:** 두 축 모두 |0.15| 미만은 중립, 한 축만 원점 인접은 경계입니다. 중립·경계·잠정이면 국면 확정 배지를 표시하지 않습니다. 경계는 지속을 끊지 않으며 포함 여부를 표시합니다.
- **후행 지표:** 기준금리 FEDFUNDS와 연준 자산 WALCL 단독 대신 시장의 2년물 금리, 순유동성, 광의 달러를 사용합니다. 가중치는 지정값이며 결과를 맞추는 최적화를 하지 않습니다.
- **상대 위치:** 주 점수는 216개월 재표준화 후 EMA3를 유지합니다. 원합성치와 1972년 이후 인과적 확장창 백분위를 함께 표시합니다. 원합성치도 지표 z의 평균이며 경제적 절대 수준을 직접 측정하지 않습니다. 상대·절대 불일치 배지는 점수와 원합성치의 반대 부호를 뜻합니다.

### 산식·관측 계약

```
z      = clamp((signal − actual-only μ₂₁₆) / actual-only σ₂₁₆, −3, +3)
raw    = Σ wᵢ·zᵢ / Σ available-z wᵢ
G, L   = EMA₃[ actual-only Z₂₁₆(raw) ]
ow     = 실제 변환 신호 관측 가중치 / 첫 관측 이후 가용 유니버스 가중치
```

롤링 통계 최소 실측 수는 48개월입니다. 유효 z 가중치 0.4 미만은 미산출입니다. G/L 관측 비중 모두 ≥0.8이면 확정 계산 행, 어느 축이든 0.4 이상 0.8 미만이면 `p:true`, 0.4 미만이면 월간 역사에서 제외합니다. 신규 지표가 존재하기 전에는 분모에 넣지 않습니다. 전체 수집 실패는 해당 지표를 가용 유니버스에서 조용히 삭제하지 않고 보수적으로 결측으로 계산하며 `meta.source_errors`에 예외 타입만 기록합니다.

월간 잠정 행은 속 빈 점이며 국면 지속·연간 평균·성과 자산 표시에서 제외됩니다. `c`는 계산월 확정 여부와 별개인 **국면 확인** 플래그입니다. 진행월 `provisional_point`는 기존처럼 별도 잠정 추정으로 유지하고 같은 끝단 이월·실측 통계 함수를 사용합니다. 진행월의 낮은 관측 비중은 그대로 표시하며 월간 역사에 합치지 않습니다.

행에는 `p, ow, cf, b, gr, lr, gp, lp, x`를 추가합니다. `meta.model_version`은 `2.0`, `meta.v1_compare`는 같은 원자료로 계산한 구 모델의 최근 36개월입니다. 비교 화면은 내부 방법론 HTML에만 표시합니다. 최초 전환 빌드는 전 기간 재계산이며 실시간 빈티지 백테스트가 아닙니다. 원자료가 나중에 수정되거나 내부 결측에 관측이 추가되면 과거 계산도 달라질 수 있습니다.

**자산 수익률** — S&P500(Shiller 월간), 나스닥(NASDAQCOM), 금(LBMA), WTI, 미국채 10Y(GS10 듀레이션 근사), 현금(TB3MS)의 기존 산식은 유지합니다. `book_dashboard.json`의 저자 확정 행과 Actions 스케줄·러너 설정도 변경하지 않습니다. pandas·numpy·certifi 이외의 외부 의존성은 추가하지 않습니다.

## 고지

부록 C의 순환 경로는 과거에 자주 관찰된 대표 이동 경로이며 다음 국면을 예측하는 규칙이 아닙니다. 미국 보조모델의 주도 산업·종목 및 섹터 로테이션도 과거 기록과 일반적 통념에 기반한 참고 자료입니다.
